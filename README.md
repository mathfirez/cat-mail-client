# cat-mail-client
Catmail client.

Supported Python version: 3.9.13


-------------
To install dependencies:
<PATH_TO_SCRIPTS_PYTHON> -m pip install -r requirements.txt -r requirements-dev.txt



-------------
To compile a new client:
<PATH_TO_SCRIPTS_VENV>/pyinstaller Catprinter.spec
Example:
`C:\Users\...\.pyenv\pyenv-win\versions\3.9.13\Scripts\pyinstaller Catprinter.spec`
